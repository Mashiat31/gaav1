# Hong Kong GAA website redesign

A presentation-ready redesign concept for Hong Kong GAA, built with Next.js and ready for Vercel.

## Deploy on Vercel

1. Unzip this folder.
2. Create a new GitHub repository and upload the files, or drag the folder into the Vercel CLI.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Keep the detected framework as **Next.js** and click **Deploy**.

No environment variables or external services are required.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before using this as the club's live site

- Confirm the membership prices and 2026 event details.
- Replace or add final approved club photography in `public/`.
- Update the email links if the club wants separate contacts for senior, junior and social enquiries.
- Point the final membership button to the club's preferred registration or payment flow.
